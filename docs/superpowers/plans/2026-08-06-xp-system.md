```python
@dataclass(frozen=True)
class Reward:
    level: int
    reward: str

@dataclass
class XPConfig:
    weights: dict[str, int]
    level_base: int
    level_growth: float
    rewards: list[Reward]

def load_xp_config(path: Path) -> XPConfig  # defaults when file/keys missing

@dataclass
class XPResult:
    total: int
    by_source: dict[str, int]  # daily, weekly_ritual, weekly_review, reflections, deep_block, rungs, exam_gates, streak_bonus
    level: int
    level_progress: int
    next_level_at: int
    unlocked: list[Reward]
    next_reward: Reward | None

def level_threshold(n: int, cfg: XPConfig) -> int  # round(base * n**growth); 0 for n <= 0

def compute_xp(
    *,
    per_syllabus: dict[str, dict],  # key -> {"cache": dict, "completion_set": set[str],
                                    #   "template_kinds": dict[str, str], "start_date": date,
                                    #   "daily_streak": int, "reflections_root": Path}
    ladder_dir: Path,
    state_log_entries: list[dict],  # concatenated across curricula
    exam_gates: int,
    cfg: XPConfig,
) -> XPResult

def to_data_block(result: XPResult) -> dict  # JSON-safe dict for data.json:
    # {total, level, level_progress, next_level_at, by_source,
    #  unlocked: [{level, reward}], next_reward: {level, reward} | None}
```

`template_kinds` maps template_id → one of `"daily" | "deep_block" | "weekly_ritual" | "none"` (Task 2 builds it from loaded templates; xp.py just consumes it — anything absent from the map or `"none"` earns 0).

Scoring rules (implement exactly):
- Cache walk per syllabus: entry counts iff `str(entry.get("todoist_task_id"))` in completion_set, `due_date >= start_date`, entry has NO `state_review_action`/`state_review_parent` key, and kind ≠ none. daily→weights["daily"], deep_block→weights["deep_block"], weekly_ritual→weights["weekly_ritual"].
- Streak bonus: for each syllabus with `daily_streak >= weights["streak_bonus_threshold"]`, add `weights["streak_bonus_per_task"] * daily_streak`.
- Reflections: for each syllabus, walk `reflections_root/<cadence>/*.md` for cadences weekly/monthly/quarterly/annual; `split_frontmatter` status == "filled" AND `_period_end(stem, cadence) >= start_date` → weights["reflection_filled"]. `_period_end`: weekly `YYYY-Www` → Sunday of that ISO week (`date.fromisocalendar(y, w, 7)`); monthly `YYYY-MM` → last day of month; quarterly `YYYY-Qn` → last day of quarter; annual `YYYY` → Dec 31; unparseable stem → skip.
- Rungs: glob `ladder_dir/*/meta.yaml`; outcome "shipped" → `rung_shipped` + (`rung_zero_extension_bonus` if no extensions else `-rung_extension_penalty * len(extensions)`), floored at `rung_shipped_floor`; outcome "failed" → `rung_failed_moved_on`; outcome null → 0.
- weekly_review: `weights["weekly_review"] *` count of DISTINCT `timestamp` values among state_log_entries whose `todoist_task_id` starts with `"lw-review-"`.
- exam_gates: `weights["exam_gate"] * exam_gates`.
- Level: largest n ≥ 0 with total ≥ level_threshold(n); level_progress = total − level_threshold(level); next_level_at = level_threshold(level+1). unlocked = rewards with `r.level <= level` (sorted by level); next_reward = lowest-level locked reward or None.
